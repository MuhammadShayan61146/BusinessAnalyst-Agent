


## Accessibility and usability basics for web interfaces

- Every form control needs a visible, programmatically associated label.
- All functions must be usable with the keyboard alone; keep a visible focus
  indicator.
- Do not rely on colour alone to convey status; add text or icons.
- Maintain sufficient colour contrast between text and background.
- Provide text alternatives for images and charts, including a table or summary
  of the data a chart shows.
- Announce loading, success and error states to assistive technology.
- Layouts should work from phone-sized to desktop screens.
- Prefer plain language in messages, and say what the user can do next when an
  error occurs.
